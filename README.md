# Team Collaboration Portal

## Overview

Team Collaboration Portal is a simple frontend web application developed using HTML, CSS, and JavaScript. The project allows users to log in, create a team, and create a meeting room through an easy-to-use interface.

This project is designed for learning frontend development concepts such as form handling, page navigation, UI design, and JavaScript interactions.

## Features

* User Login Page
* Team Platform Dashboard
* Team Creation Form
* Meeting Room Creation Page
* Success Popup Messages
* Simple Navigation Between Pages
* Responsive and User-Friendly Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
project/
│
├── login.html
├── platform.html
├── team creation.html
├── meeting.html
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `login.html` in your web browser.
4. Navigate through the application using the provided buttons and links.

## Application Flow

```text
Login Page
    ↓
Platform Dashboard
    ├── Create Team
    │       ↓
    │   Team Created Successfully
    │
    └── Create Meeting Room
            ↓
     Meeting Room Created Successfully
```
